# Medical Diagnosis AI

This project focuses on predicting diabetes using machine learning techniques. The dataset contains medical information such as glucose level, blood pressure, BMI, age, and other health-related attributes.

The data was analyzed and used to train a Random Forest Classifier for diabetes prediction.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## Model Used

* Random Forest Classifier

## Accuracy

72.08%

This project demonstrates how machine learning can be applied to assist in medical diagnosis and disease prediction.
